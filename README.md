# 地震テロップ（Android TV / TCL P79B向け）

GitHub repository: https://github.com/hayato41200/android-tv-earthquake-overlay

Android TV / Google TV上で動作する最小版です。P2P地震情報の公開APIを30秒間隔で確認し、オーバーレイ権限が許可されている場合に画面上端へ表示します。

## 表示条件

- 登録した自宅地域：震度1以上
- その他の地域：震度3以上
- 自宅地域の判定は都道府県または市区町村名の部分一致
- 表示は3分後に自動消去

## ビルド

Android Studioでこのフォルダを開き、Android SDK Platform 35とJDK 17を用意してBuild > Build APK(s)を実行してください。生成されたAPKをADBまたはUSB経由でP79Bへインストールします。

インストール後、アプリを起動して都道府県・市区町村を入力し、「保存して監視を開始」を選びます。その後「オーバーレイ権限を設定」で許可してください。「表示テスト」でPC入力中の表示を確認できます。

## 注意

このアプリは補助表示です。緊急地震速報の代替には使用しないでください。P2P地震情報APIの仕様・利用条件・可用性に依存します。ネットワーク断やテレビの省電力制御時は表示できない場合があります。
